# Week 11: Phase 1 Cashier Record Payment

This directory contains the Phase 1 worksheet for Week 11.

## How to use

Follow the steps in `worksheets/03_cashier_record_payment.md` to build the cashier record payment feature. Do not attempt the Phase 2 worksheets yet.

To verify your work, run the validation script for your OS:
- Windows (PowerShell): `.\tools\verify_week11.ps1`
- macOS/Linux/Git Bash: `./tools/verify_week11.sh`
