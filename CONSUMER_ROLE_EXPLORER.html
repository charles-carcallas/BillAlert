🛡️ Defense Callout: The 7-Day Cooperative Lag & Zero Debt Guarantee

In Bohol rural electric distribution (BOHECO I), meter readers physically record dials on day 1, but the electric cooperative takes up to 7 days to calculate dynamic kilowatt-hour tariffs. A novice developer might show "₱0.00 Due" during this window, leading consumers to assume their electricity is free. In BillAlert, Bill.isUnpriced evaluates true, balance defaults to zero so older debts aren't artificially distorted, and the UI displays "Amount pending" and "Awaiting the cooperative amount". Tapping into BillDetailsSheet shows the household their exact previous and present dial readings and energy consumed in kWh, providing full audit transparency before any money is owed.

🛡️ Defense Callout: The Security-Invoker Discovery & SQLite Epoch Defense

Standard PostgreSQL views run with security definer privileges (as the database administrator who created the view). Early in testing, selecting from raw tables correctly returned 1 row, but querying v_consumer_current_bill returned 5 rows from all neighboring consumers! To solve this, alter view ... set (security_invoker = on) was explicitly executed across all views. Now, Postgres strictly runs the underlying RLS policies (bills_select_scoped) as the calling client. Furthermore, for offline storage, AppDatabase tracks cacheEpoch. If an asynchronous network request returns right as a consumer signs out, epoch != _db.cacheEpoch triggers an immediate AuthFailure('The signed-in account changed.'), preventing stale data from writing over the newly logged-in household.
